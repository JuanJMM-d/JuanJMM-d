> Egresado de **Ingeniería en Sistemas Informáticos** · Universidad Católica de El Salvador (UNICAES)

Me gusta entender cómo funcionan las cosas por dentro y hacer que corran sin fricción: desde construir aplicaciones web en **.NET** conectadas a bases de datos relacionales, hasta administrar servidores **Linux**, desplegar servicios en contenedores y automatizar tareas repetitivas en red.

### Stack & Entorno de Trabajo

| Área | Tecnologías y Herramientas |
| :--- | :--- |
| **Backend** | `C#` · `.NET 8` · `ASP.NET Core MVC` · `Entity Framework Core` |
| **Bases de Datos** | `MariaDB` · `MS SQL Server` · `SQLite` |
| **Sistemas Linux** | `Debian` · `Fedora` · `systemd` · `journalctl` · Gestión de permisos y virtualización |
| **Contenedores y Despliegue** | `Docker` · `Docker Compose` · `Caddy` (proxy inverso y TLS automático) |
| **Redes y Acceso Remoto** | `WireGuard` · `ZeroTier` · `SSH` · `ufw` · DNS local y escenarios con `CG-NAT` |
| **Automatización y Cloud** | `Bash` · `cron` · `rsync` · `Wake-on-LAN` · `Git` / `GitHub` · Fundamentos en `AWS` y `Azure` |
