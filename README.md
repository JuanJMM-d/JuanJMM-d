Egresado de **Ingeniería en Sistemas Informáticos** por la Universidad Católica de El Salvador (UNICAES).

Perfil orientado al **desarrollo web backend** y la **administración de infraestructura Linux**, con experiencia práctica en aplicaciones `.NET` sobre bases de datos relacionales, despliegue en contenedores (`Docker` / `Docker Compose`), redes (`Caddy`, `WireGuard`, `ZeroTier`) y automatización de tareas en servidor.

---

### Stack técnico y áreas de trabajo

* **Backend:** C#, .NET 8, ASP.NET Core MVC y Entity Framework Core.
* **Bases de Datos:** Consultas y manejo de datos en MariaDB, MS SQL Server y SQLite.
* **Sistemas Operativos Linux:** Administración de entornos Linux (Debian, Fedora), `systemd`, gestión de permisos, análisis de logs con `journalctl` y entornos virtualizados.
* **Contenedores y Despliegue:** Docker, Docker Compose y proxy inverso con Caddy (TLS automático).
* **Redes y Acceso Remoto:** Configuración de DNS local, firewall (`ufw`), acceso seguro por SSH y túneles VPN (WireGuard, ZeroTier) en entornos con CG-NAT.
* **Automatización y Cloud:** Scripting en Bash, tareas programadas (`cron`), sincronización con `rsync`, Wake-on-LAN, flujo de trabajo con Git/GitHub y fundamentos académicos en AWS (EC2, S3, IAM) y Azure (VNets, NSGs, Azure Bastion, Key Vault).
