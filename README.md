> **Computer Systems Engineering**

I enjoy understanding how systems work from end to end: from structuring web application logic in **.NET** backed by relational databases, to setting up **Linux** servers, orchestrating containerized services, and automating routine tasks so infrastructure runs reliably and without friction.

* **Automation:** Reducing manual overhead through Bash scripting, scheduled jobs, and node-to-node synchronization.
